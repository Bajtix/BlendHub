# BlendHub
A project manager for *Blender*.
Its unofficial! Read [this section](https://github.com/Bajtix/BlendHub#Legal) 

## Features
* Version management
* Project management
* OpenWithBlender interface (allows you to select the blender version upon opening a file)
* Version downloading (early beta)
* (PLANNED) Settings sync

## Platform support
I wish I could make it cross platform, but it's based on Windows Forms, so maybe sometime?

## How to use?
The program is quite simple, Im sure you'll figure it out. To setup the OpenWithBlender functionality, you have to change the program associated to .blend files. If you want to use it to just open *Blender* without anything loaded, create a shortcut/script/anything that would launch it with the `-l` argument.
